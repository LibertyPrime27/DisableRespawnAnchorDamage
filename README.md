# DisableRespawnAnchorDamage
A simple Paper plugin for versions 1.21.x that disables damage to players from respawn anchors.

To install, drop it into the plugins folder of the Paper server running 1.21.x, tested on ver 1.21.11

ONLY TESTED ON A PAPER SERVER, MIGHT NOT WORK ON OTHER TYPES OF SERVER-SIDED PLUGIN LOADERS!!!
